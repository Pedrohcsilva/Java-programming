# Apresentação do Curso

## Sobre o Curso

Este é um curso **gratuito e online** de programação em Java oferecido pela **Universidade de Helsinque**, desenvolvido pelo grupo de pesquisa [Agile Education Research](https://www.helsinki.fi/en/researchgroups/data-driven-education). Trata-se de uma versão atualizada do antigo curso *Object-Oriented Programming with Java*.

O objetivo do curso é ensinar os **fundamentos de programação de computadores**, incluindo algoritmos e programação orientada a objetos, utilizando a linguagem de programação **Java**.

### Para quem é este curso?

O curso **não exige conhecimento prévio em programação**. Ele é voltado tanto para iniciantes absolutos quanto para quem já tem alguma experiência e deseja aprender Java especificamente.

### Estrutura

O curso é dividido em duas partes independentes:

| Curso | Partes | Conteúdo |
|:------|:------:|:---------|
| **Java Programming I** | 1 a 7 | Fundamentos: variáveis, condicionais, repetição, métodos, listas, orientação a objetos, algoritmos |
| **Java Programming II** | 8 a 14 | Avançado: herança, polimorfismo, interfaces, generics, streams, lambdas, interfaces gráficas |

Cada parte foi projetada para exigir **aproximadamente uma semana de estudo**, com dedicação mínima recomendada de 10 horas por parte.

### O que você aprenderá

Ao concluir o **Java Programming I**, você será capaz de:

- Escrever programas estruturados em Java
- Usar variáveis, condicionais e laços de repetição
- Criar e chamar métodos
- Trabalhar com listas, arrays e Strings
- Projetar e implementar classes e objetos
- Aplicar encapsulamento e composição
- Implementar algoritmos básicos de ordenação e busca
- Entender os paradigmas de programação

### Ferramentas necessárias

1. **Java Development Kit (JDK) versão 11 ou superior**
   - Download: [https://www.oracle.com/java/technologies/downloads/](https://www.oracle.com/java/technologies/downloads/)
   - Alternativa gratuita: [https://adoptium.net/](https://adoptium.net/)

2. **IntelliJ IDEA** (IDE recomendada)
   - Download gratuito (Community Edition): [https://www.jetbrains.com/idea/download/](https://www.jetbrains.com/idea/download/)

3. **Plugin TMC (Test My Code)**
   - Instalado dentro do IntelliJ IDEA
   - Instruções: [https://www.mooc.fi/en/installation/intellij/](https://www.mooc.fi/en/installation/intellij/)

### Como começar

1. Acesse [https://www.mooc.fi/en/sign-up](https://www.mooc.fi/en/sign-up) e crie uma conta gratuita
2. Instale o JDK 11 e o IntelliJ IDEA
3. Instale o plugin TMC no IntelliJ
4. No TMC, selecione o curso **"Java Programming I"**
5. Faça o download da Parte 1 e comece!

## Avaliação e Certificados

A avaliação é feita exclusivamente por meio dos **exercícios de programação**, corrigidos automaticamente pela ferramenta **Test My Code (TMC)**.

Para o **certificado de conclusão**, você precisa atingir pelo menos **80% dos pontos** em cada parte.

- Certificado do **Java Programming I**: ao completar 80%+ das partes 1 a 7
- Certificado do **Java Programming II**: ao completar 80%+ das partes 8 a 14

Os certificados estão disponíveis em: [https://www.mooc.fi/en/profile/completions](https://www.mooc.fi/en/profile/completions)

> **Atenção:** este curso **não oferece créditos acadêmicos** da Universidade de Helsinque.

## Perguntas Frequentes (FAQ)

**O curso é gratuito?**
Sim. O curso é completamente gratuito — material, exercícios e certificado.

**Preciso criar uma conta?**
Sim. Para usar o TMC, crie uma conta gratuita em [https://www.mooc.fi/en/sign-up](https://www.mooc.fi/en/sign-up).

**Posso estudar no meu próprio ritmo?**
Sim. Não há prazos fixos para conclusão.

**Este curso oferece créditos acadêmicos?**
Não. Apenas o certificado de conclusão. Para cursos com créditos ECTS: [https://programming-23.mooc.fi/](https://programming-23.mooc.fi/).

**Qual IDE devo usar?**
IntelliJ IDEA (Community Edition) com o plugin TMC. Instruções em [https://www.mooc.fi/en/installation/intellij/](https://www.mooc.fi/en/installation/intellij/).

**Qual versão do Java devo instalar?**
JDK versão 11. Remova outras versões que possam causar conflitos.

**Como atualizo o plugin TMC?**
No IntelliJ IDEA: **Help → Check for Updates**.

**Como baixo os exercícios das próximas partes?**
O TMC libera automaticamente ao atingir **25% dos pontos** da parte anterior.
