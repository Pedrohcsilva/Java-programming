Apresentação do Curso

Sobre o Curso

Este é um curso gratuito e online de programação em Java oferecido pela Universidade de Helsinque, desenvolvido pelo grupo de pesquisa Agile Education Research. Trata-se de uma versão atualizada do antigo curso Object-Oriented Programming with Java.

O objetivo do curso é ensinar os fundamentos de programação de computadores, incluindo algoritmos e programação orientada a objetos, utilizando a linguagem de programação Java.

Para quem é este curso?

O curso não exige conhecimento prévio em programação. É voltado tanto para iniciantes absolutos quanto para quem já tem alguma experiência e deseja aprender Java especificamente.

Estrutura

CursoPartesConteúdo
Java Programming I1 a 7Fundamentos: variáveis, condicionais, repetição, métodos, listas, orientação a objetos, algoritmos
Java Programming II8 a 14Avançado: herança, polimorfismo, interfaces, generics, streams, lambdas, interfaces gráficas

O que você aprenderá

Ao concluir o Java Programming I, você será capaz de:

  • Escrever programas estruturados em Java
  • Usar variáveis, condicionais e laços de repetição
  • Criar e chamar métodos
  • Trabalhar com listas, arrays e Strings
  • Projetar e implementar classes e objetos
  • Aplicar encapsulamento e composição
  • Implementar algoritmos básicos de ordenação e busca
  • Entender os paradigmas de programação

Ferramentas necessárias

  1. Java Development Kit (JDK) versão 11 ou superior
    Download: https://www.oracle.com/java/technologies/downloads/
    Alternativa gratuita: https://adoptium.net/
  2. IntelliJ IDEA (IDE recomendada)
    Download: https://www.jetbrains.com/idea/download/
  3. Plugin TMC (Test My Code)
    Instruções: https://www.mooc.fi/en/installation/intellij/

Como começar

  1. Acesse https://www.mooc.fi/en/sign-up e crie uma conta gratuita
  2. Instale o JDK 11 e o IntelliJ IDEA
  3. Instale o plugin TMC no IntelliJ
  4. No TMC, selecione o curso "Java Programming I"
  5. Faça o download da Parte 1 e comece!

Avaliação e Certificados

A avaliação é feita exclusivamente por meio dos exercícios de programação, corrigidos automaticamente pela ferramenta Test My Code (TMC). Você pode tentar quantas vezes quiser.

Para o certificado de conclusão, você precisa atingir pelo menos 80% dos pontos em cada parte:

  • Certificado do Java Programming I: ao completar 80%+ das partes 1 a 7
  • Certificado do Java Programming II: ao completar 80%+ das partes 8 a 14

Certificados disponíveis em: https://www.mooc.fi/en/profile/completions

Atenção: este curso não oferece créditos acadêmicos da Universidade de Helsinque. Para cursos com créditos ECTS, consulte https://programming-23.mooc.fi/.

Perguntas Frequentes (FAQ)

Sobre o curso em geral

O curso é gratuito?

Sim. O curso é completamente gratuito — material, exercícios e certificado.

Preciso criar uma conta?

Sim. Para usar o TMC e submeter exercícios, crie uma conta em https://www.mooc.fi/en/sign-up.

Posso estudar no meu próprio ritmo?

Sim. Não há prazos fixos para conclusão.

Este curso oferece créditos acadêmicos?

Não. Apenas certificado de conclusão. Para créditos ECTS: https://programming-23.mooc.fi/.

Sobre instalação e ferramentas

Qual IDE devo usar?

IntelliJ IDEA (Community Edition, gratuita) com o plugin TMC. Instruções em https://www.mooc.fi/en/installation/intellij/.

Qual versão do Java devo instalar?

JDK versão 11. Remova versões mais antigas para evitar conflitos.

Estou recebendo erro sobre JAVA_HOME. Como resolver?

Verifique se o JDK 11 está instalado e configure a variável de ambiente JAVA_HOME apontando para o diretório de instalação do JDK.

Sobre o plugin TMC e exercícios

Como atualizo o plugin TMC?

No IntelliJ IDEA: acesse Help → Check for Updates.

Como baixo os exercícios das próximas partes?

O TMC libera automaticamente ao atingir 25% dos pontos da parte anterior. Você também pode baixar manualmente pelo menu TMC.

Como reporto um possível bug em um exercício?

Primeiro verifique se o erro está no seu código (peça ajuda no Discord). Se confirmar que é um bug, notifique os assistentes no Discord.
